# Overscan logo

The mark is a picture that is bigger than the screen: a disc cropped by a
rounded screen frame, with the cropped part ghosted out above and below. That
is overscan.

## Files

| File | Use |
| --- | --- |
| `overscan-lockup-on-dark.svg` | Mark and wordmark, for dark backgrounds |
| `overscan-lockup-on-light.svg` | Mark and wordmark, for light backgrounds |
| `overscan-mark-on-dark.svg` | Mark only, for dark backgrounds |
| `overscan-mark-on-light.svg` | Mark only, for light backgrounds |
| `overscan-icon.svg` | App-style icon: mark on a rounded dark tile |
| `overscan-icon-512.png` | 512 × 512 PNG render of the icon |
| `overscan-social-preview.png` | 1280 × 640 link-preview image |

## Palette

| Name | Value | Where |
| --- | --- | --- |
| Ink | `#0F1424` | Dark background, mark and wordmark on light |
| Paper | `#F5F3EC` | Light background, frame and wordmark on dark |
| Teal (on dark) | `#3DD9C1` | The disc on dark backgrounds |
| Teal (on light) | `#0B8F7E` | The disc on light backgrounds |

The ghosted part of the disc is the same teal at 40% opacity.

## Usage

- Use the "on dark" files on dark backgrounds and the "on light" files on light
  ones. Do not recolour the disc.
- Leave clear space around the logo of at least the height of the screen frame.
- Keep the mark at 16 px or larger. Below 32 px, use the mark without the
  wordmark.
- Do not combine the logo with Infomir, Stalker, Ministra or MAG names or marks.
